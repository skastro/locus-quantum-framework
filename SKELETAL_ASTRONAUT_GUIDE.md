## 💫 THE COSMIC ENVIRONMENT

### **Nebula Clouds (Four Elements):**

**Placement:**
- Four corners of the canvas
- Each represents an element
- Radiating from corner points
- 40-70 particles per cloud

**Characteristics:**
- Soft, diffuse glow
- Varying opacity
- 2-8 pixel radius particles
- Fade toward edges
- Create atmospheric depth

**Symbolism:**
- **Wisteria (Top-left)** = Air element, mental clarity
- **Pink (Top-right)** = Fire element, creative passion
- **Sage (Bottom-left)** = Earth element, grounded structure
- **Periwinkle (Bottom-right)** = Water element, mystical flow

### **Stars (Infinite Detail):**

**Distribution:**
- 200-500 stars depending on canvas size
- Random placement avoiding astronaut
- Mix of bright and dim
- Various sizes (1-3 pixel radius)

**Meaning:**
- Each star = an infinitesimal point
- Collectively = infinite essence
- Scattered = mapping the void
- Eternal = timeless presence

### **The Void:**

**Pure Black Background:**
- Subtle gradient (top lighter than bottom)
- Creates depth without distraction
- Emphasizes isolation
- Represents infinite possibility
